Training Data 
--------------
Since the algorithm fundamentally relies on investigating a person's future through
text analytics, word2vec (w2v) plays a pivotal role, meaning that developing a 
well-defined and consistent vector space is crucial. As a result, we establish such
a vector space by reading in data and transforming it from resumes availabe on Indeed.
