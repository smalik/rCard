# Plytos

**Play to your strengths.** Plytos is a candidate-owned vault of evidence-backed
"strength cards" that job seekers build once, version over a lifetime, and
recombine for each application.

This repository previously held R-Card (2014 to 2017). That code is not carried
forward. This `main` branch starts with a clean history.

## Where the old code went

The 2014 to 2017 R-Card code is preserved, read-only, and is not used by Plytos:

| Ref | What it is |
| --- | --- |
| `master` branch (deprecated) | R-Card Flask/MongoDB app, last commit March 2017 |
| `develop` branch (deprecated) | R-Card develop line, last commit 2016 |

Do not branch from or merge the legacy refs into `main`. Their history contains
credentials that were committed in plaintext and must be treated as compromised.
